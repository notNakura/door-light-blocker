# Changelog

## [1.0.0] - 2026-09-30

- Closed doors block light like a solid block; open doors let light through.
- JSON config (`config/door_light_blocker.json`) with a default value plus optional per-group and per-door overrides.
- Optional in-game config screen via Mod Menu + YACL.
- Config changes apply without restart in singleplayer; light refreshes when a door is opened or closed.
